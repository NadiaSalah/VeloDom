Accessible attributes and stylesBindings

Toggle a boolean directly into aria-pressed. CSS variables keep their exact spelling, and old bound styles disappear when their value is replaced.

Ordinary HTML, reactive presentation.

attributes + stylesno custom helper
<button vd-on:click="toggleBinding()"
  vd-attr="{ 'aria-pressed': bindingActive }">Toggle</button>

// script.js
export function init({ state }) {
  state.toggleBinding = () => {
    state.bindingActive = !state.bindingActive;
  };
}
