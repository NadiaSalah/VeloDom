01 · package map

Import only the capability you need.

The main entry contains browser runtime and authoring helpers. Compiler, content, assets, localization, Node, testing, and tool integrations use explicit subpaths so optional build-time code never enters the browser accidentally.

ImportResponsibilityBrowser runtime?
velodomApp, state, plugins, requests, authWhen imported
velodom/viteConvention-first application bootstrapCreates runtime
velodom/compilerTemplate compilation and editor analysisBuild/tooling
velodom/contentMarkdown, indexes, SEO, sitemap, RSSNode/build

02 · runtime and authoring

Small defaults, explicit advanced composition.

mountVeloDom() is the beginner path. The main package exposes lower-level application, reactive, authoring, direction, shared-state, validation, progressive-form, plugin, cache, retry, and devtools helpers when a project needs them.

runtime valuesvelodom
import {
  computed, createApp, createDirectionPlugin, createPluginManager,
  createProgressiveFormsPlugin, createRequestCache, createSharedState,
  createValidationPlugin, definePageConfig, definePlugin, effect,
  watch, withRequestRetry
} from "velodom";

const total = computed(() => state.price * state.quantity);
const stop = watch(() => state.query, search);

const ui = createSharedState({ theme: "system" }, { name: "ui" });

createApp({ adapter, plugins: [ui.plugin] });
ui.state.theme = "dark";

Also public for conformance and integrations: defineResourceAdapter, assertResourceAdapterConformance, assertPluginConformance, createRtlFlipStyles, and createDevtoolsPlugin. Use them only when authoring infrastructure rather than an ordinary page.

03 · data boundary

Requests, middleware, and auth share one policy engine.

advanced request APIvelodom
import {
  ApiError, VD_AUTH, VD_MIDDLEWARE, VD_REQUEST,
  createAuthRuntime, createServerSessionAuthProvider,
  defineRequestMiddleware, defineRequestRoute,
  normalizeAuthSession, requestJson
} from "velodom";

export const audit = defineRequestMiddleware(async (context, next) => {
  const startedAt = performance.now();
  const result = await next();
  console.info(context.route, performance.now() - startedAt);
  return result;
});

const post = await requestJson("/api/posts/1");

createLocalStorageAuthProvider is a demonstration/client-only provider. Prefer createServerSessionAuthProvider for production session authority. Constants centralize framework-owned request defaults; application routes and middleware remain under src/api.

04 · compiler

Validate HTML and select runtime features before delivery.

compiler APIvelodom/compiler
import {
  analyzeVeloDomDocument, compileTemplate,
  createRuntimeFeatureManifest, defineTemplateOptimizer,
  getVeloDomDirectiveCompletions, runTemplateOptimizers
} from "velodom/compiler";

const result = compileTemplate('<button vd-on:click="save()">Save</button>', {
  filename: "src/pages/editor/index.html"
});

console.log(result.code, result.metadata);
console.log(createRuntimeFeatureManifest(result.metadata));

Compiler APIs power Vite, diagnostics, editor completions, project intelligence, and optional optimizers. They do not create a second template language or execute application expressions through eval.

import {

const posts = await loadContentCollection({

const rss = createContentRssFeed(posts.entries, {

createContentCollection composes parsing, indexes, SEO, sitemap, and search output. Use the individual pure helpers for custom build pipelines; use loadExternalContentCollection to normalize CMS records without shipping credentials or vendor SDKs to the browser.

06 · localization and RTL

Typed messages and locale SEO without a mandatory i18n runtime.

src/localization.jsvelodom/localization
import {
  createLocaleFormatter, createLocalization, defineLocaleDictionary,
  generateLocaleKeyDeclaration, inspectLocalization
} from "velodom/localization";

const options = {
  defaultLocale: "en",
  locales: {
    en: { lang: "en", messages: defineLocaleDictionary({ hello: "Hello" }) },
    ar: { lang: "ar", messages: defineLocaleDictionary({ hello: "مرحبا" }) }
  }
};

const i18n = createLocalization(options);
i18n.t("ar", "hello");
createLocaleFormatter("ar-EG").formatCurrency(1200, "EGP");
inspectLocalization(options);

07 · asset quality

Inspect images at build time; use native browser behavior at runtime.

asset auditvelodom/assets
import {
  createResponsiveImageAttributes, inspectImageAsset, inspectImageDirectory
} from "velodom/assets";

const report = await inspectImageDirectory({
  root: "src/assets", maxBytes: 300_000
});

const image = createResponsiveImageAttributes({
  src: "/hero-960.webp",
  variants: [
    { src: "/hero-480.webp", width: 480 },
    { src: "/hero-960.webp", width: 960 }
  ],
  sizes: "(max-width: 640px) 100vw, 960px"
});

inspectImageAsset reads one file; directory inspection reports oversized assets. VeloDom generates standard attributes, while the application's chosen image pipeline owns resizing and compression.

The Node adapter converts Node HTTP to Fetch request/response semantics; it is not automatic SSR. The devtools inspector is read-only and development-only. Test mounts use browser-like DOM environments and preserve normal lifecycle cleanup.
