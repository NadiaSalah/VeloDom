A structured learning path

From your first page to production boundaries.

Each lesson explains a public VeloDom capability, why it exists, and how to use it in code. The examples on this site are built from the same folders and components they teach.

A deliberate boundary

JSX, a virtual DOM, a global store, SSR, CSS tooling, and AI are never mandatory. Use ordinary HTML first, then add only the VeloDom feature that solves the current problem.

Visible code, no hidden magic

A page is a folder. HTML is the template.

This is the core authoring contract. Route, SEO, styles, behavior, and data remain in nearby files that a beginner can find without a custom registration layer.
