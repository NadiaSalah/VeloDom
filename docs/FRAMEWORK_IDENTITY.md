# VeloDom Framework Identity

## Positioning

VeloDom is an HTML-first, compiler-first frontend framework for developers who
want the productivity of declarative UI, routing, components, requests, and
SEO tooling while continuing to author normal HTML, JavaScript, or TypeScript.

## Who VeloDom Is For

VeloDom is for teams building content-heavy sites, dashboards, docs, blogs,
marketing pages, CRUD tools, and small-to-medium SPAs where HTML clarity,
static analysis, SEO, and low runtime complexity matter.

## What VeloDom Does Better Than Plain JavaScript

VeloDom keeps the directness of HTML but removes repetitive glue code for:

- reactive text and attributes
- conditional and list rendering
- page routing
- components and slots
- request loading/error/result state
- middleware and auth coordination
- SEO metadata and static route output
- compiler diagnostics and project inspection

## When To Choose VeloDom Over Heavier Frameworks

Choose VeloDom when the project benefits from declarative templates and
framework conventions, but does not need a virtual DOM, JSX/TSX, mandatory
global stores, complex server rendering, or a large component runtime.

## What VeloDom Intentionally Does Not Solve

VeloDom intentionally does not try to be React, Vue, Angular, or a universal
SSR framework. It does not provide JSX/TSX, a mandatory global store, a
compatibility runtime for other frameworks, mandatory AI, or hidden build-time
magic that makes HTML ownership unclear.
